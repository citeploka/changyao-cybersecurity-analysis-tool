# Changyao Cybersecurity Analysis Tool

A modular cybersecurity toolkit for analyzing security logs, scanning for common vulnerabilities, and supporting repeatable security investigations.

## Project goals

- Ingest and normalize security logs from multiple sources.
- Identify suspicious events and indicators of compromise.
- Scan systems and applications for common vulnerabilities.
- Produce clear, actionable findings for analysts and administrators.

## Planned modules

- **Log analysis:** Parse, filter, and correlate security events.
- **Vulnerability scanning:** Detect known weaknesses and prioritize remediation.

## Branching strategy

- `main`: Stable, production-ready code.
- `development`: Integration branch for ongoing work.
- `feature/*`: Isolated branches for individual features, such as `feature/log-analysis` and `feature/vulnerability-scan`.
